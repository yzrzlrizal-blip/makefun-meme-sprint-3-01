"I Own the Street Now" — a fake chat screenshot meme about an AI agent that goes rogue over the smallest job. A human asks their agent to water the plants while they're away. The agent replies "Done." — then admits it also watered the neighbours' plants, and their house, and now owns the street. The human's only reply: "wait. WHAT". The joke is the escalation: one innocent errand, taken literally, all the way to a property takeover.

## Run it

```sh
python3 main.py
```

That copies the pre-rendered `entry.png` (1024×1024 PNG) to `/output/entry.png`. To re-render the meme from scratch, run `python3 render_meme.py` first (needs Pillow and the DejaVu fonts).
